Completeness

Dataset Completeness Assessment

This analysis evaluates how complete the datasets are by measuring missing values and the fill rate of metadata fields. Higher completeness indicates fewer missing values in critical fields.

  • Missing Data Percentage — The proportion of all values across the entire dataset that are missing (NaN).
  • Required Fields Completeness — The fill rate (as a percentage) specifically for the fields designated as required.
  • Per-Field Completeness — A field-level breakdown reporting the percentage of non-missing values for each required column individually.
